# Hospital-Emergency-Room-Data-Analysis-Dashboard
Interactive Excel dashboard analyzing hospital emergency room data, including patient volume, average wait time, satisfaction score, admission status, gender, age groups, department referrals, and on-time attendance. Built with Excel PivotTables, PivotCharts, KPIs, slicers, and interactive visualizations.
# Hospital Emergency Room Data Analysis Dashboard

## 📊 Project Overview

An interactive Microsoft Excel dashboard designed to analyze and monitor hospital emergency room performance through key patient and operational metrics.

The dashboard provides a monthly report view with interactive filters and visualizations to understand patient volume, waiting time, satisfaction, admission status, demographics, department referrals, and attendance timing.

## 🎯 Key KPIs

- Total Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Admission Status
- Patient Attendance Within Time

## 📈 Dashboard Analysis

The dashboard analyzes:

- Patient volume by month
- Average patient wait time
- Patient satisfaction score
- Admitted vs. not admitted patients
- Patient attendance: On Time vs. Delay
- Patient distribution by gender
- Patient distribution by age group
- Department-wise patient referrals

## 🔍 Key Features

- Interactive monthly filter
- Year selection for 2023 and 2024
- KPI cards for important performance metrics
- Interactive charts and visualizations
- Admission status analysis
- Gender and age-group analysis
- Department referral analysis
- Patient attendance analysis
